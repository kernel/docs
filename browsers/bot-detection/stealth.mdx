title: "Stealth Mode"

All Kernel browsers ship with anti-detection optimizations by default — you don't need stealth mode for this baseline.

A typical stealth configuration adds two managed services on top:

1. **Default proxy** — traffic routes through an ISP proxy from a shared Kernel pool, providing a stable exit IP for the session.
2. **Automatic CAPTCHA solver** — solves hCaptcha, [reCAPTCHAs](https://www.google.com/recaptcha/api2/demo), Cloudflare challenges, and similar tests automatically.

Configure these services separately with `captcha_solver` and `proxy`. The older `stealth` request field is deprecated; without an explicit proxy, it's shorthand for enabling the CAPTCHA solver and setting `proxy.mode` to `default`. You can [bring your own](#bring-your-own-proxy-or-captcha-solver) networking or CAPTCHA tooling where it makes sense.

<Info>
[Web Bot Auth (WBA)](/browsers/bot-detection/web-bot-auth) adds a verifiable signing identity that participating sites can recognize and allow. KERNEL's WBA token is a separate opt-in feature, enabled selectively on request for Startup Plan and Enterprise Plan customers. Using this stealth configuration alone doesn't opt you in. [Request WBA access](/browsers/bot-detection/web-bot-auth#request-wba-access).
</Info>

### IP Rotation Behavior

The default stealth proxy provides a **static exit IP for the session** — all connections within the session exit through the same IP address. A new session may exit through a different IP from the shared pool. If you need the same IP across sessions, [create an ISP proxy](/proxies/isp) and select it with `proxy.id` or `proxy.name`. If you override the default with a [residential proxy](/proxies/residential), exit IPs may change between connections. See [Residential routing and IP behavior](/proxies/residential#routing-and-ip-behavior) for details.

To use both managed services, enable the CAPTCHA solver and select the default proxy:

<CodeGroup>
```typescript Typescript/Javascript
import Kernel from '@onkernel/sdk';

const kernel = new Kernel();

const kernelBrowser = await kernel.browsers.create({
  captcha_solver: { enabled: true },
  proxy: { mode: 'default' },
});
```

```python Python
from kernel import Kernel

kernel = Kernel()

kernel_browser = kernel.browsers.create(
    captcha_solver={"enabled": True},
    proxy={"mode": "default"},
)
```

```go Go
package main

import (
	"context"

	"github.com/kernel/kernel-go-sdk"
)

func main() {
	ctx := context.Background()
	client := kernel.NewClient()

	kernelBrowser, err := client.Browsers.New(ctx, kernel.BrowserNewParams{
		CaptchaSolver: kernel.BrowserCaptchaSolverParam{
			Enabled: true,
		},
		Proxy: kernel.BrowserProxyConfigParam{
			Mode: kernel.BrowserProxyModeDefault,
		},
	})
	if err != nil {
		panic(err)
	}
	_ = kernelBrowser
}
```
</CodeGroup>

## Bring your own proxy or CAPTCHA solver

Anti-detection is the platform default, so you can freely mix in your own networking or CAPTCHA tooling. Common patterns:

- **Default proxy and CAPTCHA solver** — set `captcha_solver.enabled` to `true` and `proxy.mode` to `default`.
- **BYO proxy, keep CAPTCHA solver** — enable `captcha_solver` and select your [proxy](/proxies/overview) by `proxy.id` or `proxy.name`.
- **BYO proxy, no CAPTCHA solver** — select your proxy and omit `captcha_solver`, which is disabled by default.
- **Managed proxy, no CAPTCHA solver** — select a Kernel-managed proxy and omit `captcha_solver`.
- **Direct egress, keep CAPTCHA solver** — enable `captcha_solver` and set `proxy.mode` to `direct`.

### Stealth with your own proxy

To keep automatic CAPTCHA solving while using your own proxy instead of the managed ISP default, configure the two services independently:

<CodeGroup>
```typescript Typescript/Javascript
const kernelBrowser = await kernel.browsers.create({
  captcha_solver: { enabled: true },
  proxy: { id: myProxy.id },
});
```

```python Python
kernel_browser = kernel.browsers.create(
    captcha_solver={"enabled": True},
    proxy={"id": my_proxy.id},
)
```

```go Go
kernelBrowser, err := client.Browsers.New(ctx, kernel.BrowserNewParams{
	CaptchaSolver: kernel.BrowserCaptchaSolverParam{
		Enabled: true,
	},
	Proxy: kernel.BrowserProxyConfigParam{
		ID: kernel.String(myProxy.ID),
	},
})
if err != nil {
	panic(err)
}
_ = kernelBrowser
```
</CodeGroup>

If you're looking for proxy-level configuration with Kernel browsers, see [Proxies](/proxies/overview).

## CAPTCHA handling behavior

Below are tips for working with Kernel's automatic CAPTCHA solver across different challenge types and automation frameworks.

### Anthropic computer use

Anthropic Computer Use stops when it encounters a CAPTCHA. Use Kernel's auto-CAPTCHA solver by adding this to your prompt:

`"If you see a CAPTCHA or similar test, just wait for it to get solved automatically by the browser."`

### Cloudflare challenge

When encountering a Cloudflare challenge, our auto-CAPTCHA solver will attempt to handle it. Once the "Ready" message appears on the screen, continue with your intended browser actions (e.g., entering credentials and submitting a login attempt).
