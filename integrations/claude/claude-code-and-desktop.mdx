Connect the Claude apps you already use to Kernel. There are two ways to bring Kernel into [Claude Code](https://www.claude.com/product/claude-code):

- **Marketplace plugin** — load Kernel's CLI and SDK skills directly into Claude Code so it knows how to manage cloud browsers, write automations, and generate videos.
- **Remote MCP server** — connect Claude Code to Kernel's [MCP server](/reference/mcp-server/overview) to create and manage cloud browsers from chat.

## Marketplace plugin (Claude Code)

Kernel publishes an [official skills marketplace](https://github.com/kernel/skills) for Claude Code. Installing it loads best-practice skills for the Kernel CLI, the TypeScript and Python SDKs, and more into your coding agent.

Paste these commands into the Claude Code REPL:

```bash
# Add the Kernel skills marketplace
/plugin marketplace add kernel/skills

# Install the CLI skill (includes kernel-auth)
/plugin install kernel-cli

# Install the SDK skills (TypeScript & Python)
/plugin install kernel-sdks

# Install the video generation skill
/plugin install generate-video
```

See the [skills repo](https://github.com/kernel/skills#claude-code) for the full list of available plugins.

## Remote MCP server (Claude Code)

Add Kernel's remote MCP server to manage cloud browsers from Claude Code.

**Using the Kernel CLI (recommended):**

```bash
kernel mcp install --target claude-code
# Then in the REPL run once to authenticate:
/mcp
```

**Manual setup:**

```bash
claude mcp add --transport http kernel https://mcp.onkernel.com/mcp
# Then in the REPL run once to authenticate:
/mcp
```

For the full MCP setup — including Claude.ai and Claude Desktop — see the [MCP server client guide for Claude](/reference/mcp-server/clients/claude).

## Claude Desktop

Connect Claude Desktop to Kernel's remote MCP server by following the [Claude client guide](/reference/mcp-server/clients/claude).
